Una entidad bancaria desea desarrollar un sistema básico para representar cuentas de clientes. Cada cuenta debe almacenar el nombre del titular y su saldo disponible, pero estos datos no deben ser accesibles directamente desde fuera de la clase, para evitar modificaciones incorrectas.
Para ello, se debe implementar una clase en Python llamada CuentaBancaria, la cual utilizará el concepto de encapsulamiento, protegiendo sus atributos mediante variables privadas y controlando el acceso a través de métodos especiales.
La clase debe permitir realizar operaciones básicas como consultar datos, modificar el nombre del titular de forma segura, realizar depósitos y retiros validando las condiciones necesarias.
