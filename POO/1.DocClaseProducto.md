# Clase Producto - Conceptos de POO en Python

Este documento explica los conceptos que aparecen en el ejercicio `1.ClaseProducto.py`.

## 1. ¿Qué es una clase?
Una clase es un molde o plantilla para crear objetos.

En el ejercicio:

```python
class Producto:
```

`Producto` define como sera cualquier producto que creemos (que datos tendra y que acciones podra hacer).

## 2. ¿Qué es un objeto (instancia)?
Un objeto es una copia concreta creada a partir de una clase.

En el ejercicio:

```python
p1 = Producto(1, "Producto 1", 100)
p2 = Producto(2, "Producto 2", 200)
p3 = Producto(3, "Producto 3", 300)
```

`p1`, `p2` y `p3` son instancias de la clase `Producto`.

## 3. Atributos
Los atributos son variables que pertenecen a cada objeto.

En este caso, los atributos son:
- código
- nombre
- precio

En este ejercicio se usan como atributos públicos:
- `self.codigo`
- `self.nombre`
- `self.precio`

## 4. ¿Qué es un método?
Un metodo es una funcion definida dentro de una clase.

Ejemplos en el ejercicio:
- `__init__` (constructor)
- `calcular_total`
- `__str__`

## 5. ¿Qué es self?
`self` representa al objeto actual.

Sirve para acceder a los datos del mismo objeto.

Ejemplo:

```python
self.precio = precio
```

Significa: "al atributo `precio` de este objeto le asigno el valor recibido".

## 6. Constructor (<code>\_\_init__</code>)
El constructor es el método que se ejecuta automáticamente al crear un objeto.

En el ejercicio:

```python
def __init__(self, codigo, nombre, precio):
    self.codigo = codigo
    self.nombre = nombre
    self.precio = precio
```

Su función es inicializar los atributos del producto desde el inicio.

## 7. Método especial <code>\_\_str__</code>
`__str__` define como se mostrara el objeto al usar `print(objeto)`.

En el ejercicio, devuelve un texto con codigo, nombre y precio.

Por eso cuando haces `print(p1)`, sale una descripcion legible del producto.

## 8. Método de negocio: `calcular_total`
Este metodo recibe una cantidad de unidades y calcula el total:

```python
def calcular_total(self, unidades):
    return self.precio * unidades
```

Usa el precio del objeto y lo multiplica por las unidades.

## Resumen rapido
En este ejercicio practicas:
- Definir una clase (`Producto`)
- Crear objetos (instancias)
- Usar constructor (`__init__`)
- Usar `self`
- Trabajar con atributos publicos
- Definir metodos (`calcular_total`)
- Mostrar objetos con `__str__`
